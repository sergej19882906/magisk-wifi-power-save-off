# Changelog

All notable changes to this project are documented in this file.

## [1.0.1] - 2026-11-09

### Added

- First public release.
- Automatic Wi-Fi interface discovery with a `wlan0` fallback.
- Reapplication of `power_save off` every 30 seconds after driver resets.
- Best-effort restoration of the state saved during installation.
- Reproducible ZIP builder, verifier, bilingual documentation, and CI.
