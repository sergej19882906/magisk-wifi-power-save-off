# Magisk Wi-Fi Power Save Off

[English version](README.md)

Magisk-модуль, который отключает энергосбережение Wi-Fi через `iw` и каждые 30 секунд проверяет активный Wi-Fi-интерфейс. Если драйвер или прошивка снова включает power save после переподключения либо перезапуска, модуль повторно его отключает.

Это может помочь Android TV-устройствам, у которых Wi-Fi становится недоступен или обрывается в простое либо standby. Модуль не заменяет правильную настройку роутера и не может исправить все ошибки драйверов и прошивок.

## Важное предупреждение

Отключение энергосбережения Wi-Fi может увеличить потребление энергии в режиме ожидания и температуру устройства. На устройствах с аккумулятором оно сокращает время работы. Модуль предназначен прежде всего для Android TV с постоянным сетевым питанием.

Модуль запускает небольшой shell-цикл с пробуждением раз в 30 секунд. Он не изменяет `/system`, не использует Zygisk, не устанавливает нативные бинарники и не обращается к сети.

## Требования

- Android-устройство с root и Magisk.
- `/system/bin/iw` с поддержкой `get power_save` и `set power_save`.
- Драйвер с управлением power save через nl80211.

Проверено на:

- Xiaomi `MiTV-AFKR0`
- Android 14 (SDK 34)
- Magisk 31.1
- MediaTek `mt7663_usb`, интерфейс `wlan0`
- SELinux enforcing

Другие устройства и драйверы могут работать, но пока не проверены.

## Установка

1. Скачайте устанавливаемый ZIP и `SHA256SUMS` из последнего [релиза GitHub](https://github.com/sergej19882906/magisk-wifi-power-save-off/releases/latest).
2. Проверьте контрольную сумму ZIP.
3. Откройте Magisk, выберите **Модули → Установить из хранилища** и укажите скачанный ZIP.
4. Перезагрузите устройство.

Не устанавливайте автоматически созданный GitHub-архив **Source code**. Используйте ZIP, приложенный к релизу.

## Проверка

После перезагрузки выполните:

```sh
su -c 'iw dev wlan0 get power_save'
```

Ожидаемый результат:

```text
Power save: off
```

Если интерфейс называется иначе, определите его командой:

```sh
getprop wifi.active.interface
```

Диагностический журнал:

```sh
su -c 'cat /data/adb/modules/wifi_power_save_off/service.log'
```

## Как это работает

- Во время установки модуль по возможности сохраняет текущее состояние `power_save`.
- При загрузке `service.sh` определяет активный интерфейс через свойства Android и использует `wlan0` как запасной вариант.
- Раз в 30 секунд он проверяет состояние драйвера и при необходимости меняет его на `off`.
- При отключении или удалении модуль восстанавливает состояние, сохранённое во время установки.

## Отключение и удаление

- **Отключение:** отключите модуль в Magisk. Работающий цикл обнаружит маркер отключения, восстановит сохранённое состояние и завершится; перезагрузитесь для завершения штатного процесса Magisk.
- **Удаление:** удалите модуль через Magisk. `uninstall.sh` остановит цикл и попытается восстановить исходное состояние. После этого перезагрузитесь.

Ручной откат:

```sh
su -c 'iw dev wlan0 set power_save on'
```

## Решение проблем

### `iw` сообщает `command failed` или не показывает состояние

Драйвер может не поддерживать управление через nl80211, интерфейс может называться иначе либо операция заблокирована SELinux-политикой производителя. Отключите или удалите модуль.

### Wi-Fi всё равно отключается

Причиной может быть глубокий suspend, выгрузка USB Wi-Fi-драйвера службой производителя, поведение точки доступа, истечение DHCP, помехи или ошибка прошивки. Этот модуль управляет только флагом энергосбережения драйвера. Если устройство уходит в глубокий сон, дополнительно может потребоваться kernel wakelock.

### Устройство нагревается или потребляет больше энергии

Отключите либо удалите модуль и перезагрузитесь. Увеличение потребления — ожидаемый возможный эффект.
